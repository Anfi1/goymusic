# «Подобрать» — кастомный микс по настроениям в «Моей волне»

Дата: 2026-07-01
Ветка: `feature/mywave-curate-mix`
Статус: дизайн согласован, готов к плану реализации

## 1. Проблема и цель

Сейчас «Жанры/Настроения» в `MyWaveView` — это одиночный фильтр колеса станций,
где категории (`MOOD_CATEGORIES`) назначаются клиентски по ключевым словам в
названиях миксов (`assignCategory`). Хочется дать пользователю собрать
**собственный микс**, натыкав несколько тегов-настроений, и получить единую
«станцию» из перемешанных треков этих настроений.

**Цель:** добавить в «Мою волну» действие **«Подобрать»** — мультивыбор
настроений → синтетическая станция «🎛 Мой подбор» с перемешанным трек-листом,
которая играется как обычная станция. Фильтр «Все» и всё остальное — без изменений.

## 2. Ключевые решения (согласованы)

- **Источник тегов — только настроения из персонального пула** пользователя
  (`get_mixed_for_you`), т.к. он персонализирован и русскоязычен.
- **Глобальный mood/genre-каталог YouTube (`get_mood_categories`/`get_mood_playlists`)
  отклонён.** Эмпирически проверено: контент почти целиком зарубежный
  (в сэмплах 1–9% русских треков: «Заряд энергии» → 1/89, «Вечеринка» → 9/100,
  «Грустная» → 3/80), а раздел «Жанры» вообще падает с ошибкой парсера в форке
  ytmusicapi. Жанры как отдельное измерение — **вне scope этой итерации.**
- **Сборка микса — чисто клиентская** (никаких правок Python): берём треки из
  уже существующих миксов пула через `getPlaylistTracks`.
- **UX:** чип «+ Подобрать» в ленте фильтров → поповер с чек-боксами настроений
  → «Собрать микс» → станция «Мой подбор» в начале колеса, играется как обычная.

## 3. Архитектура и поток данных

```
выбранные настроения (moodIds: string[])
   │
   ├─ pickMixesForMoods(moodIds, stations)
   │     для каждого настроения — его YT-миксы из пула
   │     (kind:'yt', сгруппированы через assignCategory(groupKey(title)))
   │
   ├─ для каждого выбранного микса: getPlaylistTracks(mix.id, ~30)   ← существующий вызов
   │     (1–2 микса на настроение, чтобы не перегружать)
   │
   ├─ blendTracks(perMoodTrackLists, cap=60)
   │     round-robin по настроениям + дедуп по track.id + лёгкий шаффл
   ▼
curatedTracks: YTMTrack[]
   │
   ├─ синтетическая станция CURATED (id:'curated') добавляется в начало колеса
   ▼
startStation(CURATED) → player.playTrackList(curatedTracks, 0, WAVE_SOURCE_ID)
```

Трек-лист **конечный** (не бесконечное радио) — по согласованию. `recId` при
воспроизведении не задаётся.

## 4. Модули и компоненты

### 4.1 `src/utils/curatedMix.ts` (новый; чистые функции — юнит-тестируемы)

- `moodTagCategories(): MoodCategory[]` — mood-категории для панели
  (исключая `all`, `genre`, `soundcloud`).
- `pickMixesForMoods(moodIds: string[], stations: WaveStation[]): Record<string, WaveStation[]>`
  — для каждого настроения его YT-миксы (та же логика `assignCategory(groupKey(title))`,
  что уже используется в `visibleStations`).
- `blendTracks(trackLists: YTMTrack[][], cap?: number): YTMTrack[]`
  — round-robin по спискам, дедуп по `id`, лёгкий детерминированно-случайный шаффл,
  ограничение `cap` (по умолчанию 60). Чистая функция.

### 4.2 `MyWaveView.tsx`

- Состояние: `curateOpen: boolean`, `curatedMoods: string[]`,
  `curatedTracks: YTMTrack[]`, `curateBuilding: boolean`.
- Синтетическая станция `CURATED: WaveStation = { id: 'curated', title: 'Мой подбор', kind: 'curated', thumbUrl: '' }`
  — рендерится в начале колеса, когда `curatedTracks.length > 0`.
  Подзаголовок: «Подбор: <настроения>».
- Ветка в `startStation` для `st.kind === 'curated'`: играет готовый `curatedTracks`
  без сетевого фетча (`player.playTrackList(curatedTracks, 0, WAVE_SOURCE_ID)`).
- `buildCuratedMix()`: `pickMixesForMoods` → параллельные `getPlaylistTracks`
  (с `Promise.allSettled`, упавшие миксы пропускаем) → `blendTracks` →
  `setCuratedTracks` → `startStation(CURATED)`.
- Тип `WaveStation.kind` расширяется значением `'curated'`.

### 4.3 Панель `CuratePanel` (поповер под чипом)

- Список mood-категорий с цветными чек-боксами (`--mood-color`), мультивыбор.
- Кнопка «Собрать микс (N)» — неактивна при 0 выбранных; спиннер во время сборки.
- Реализация — внутри `MyWaveView` или отдельная молекула
  `src/components/molecules/CuratePanel.tsx` (решается на этапе плана; предпочтительно
  отдельный файл, если разрастётся).
- Чип «+ Подобрать» — в `filterStrip` рядом с чипами настроений; клик тогглит `curateOpen`.

## 5. Состояние и жизненный цикл

- Последний выбор настроений — в `localStorage` под ключом `ytm-curated-moods`
  (в стиле остальных `ytm-*`), чтобы «Мой подбор» восстанавливался между заходами.
- Станция одна (`id:'curated'`); повторная сборка перезаписывает `curatedTracks`.
- При старте раздела: если в `localStorage` есть сохранённые настроения — станцию
  можно показать «лениво» (пересобрать по клику), трек-лист не кэшируем на диск.

## 6. Крайние случаи и обработка ошибок

- 0 выбранных настроений → кнопка «Собрать» неактивна.
- У выбранных настроений нет миксов в пуле → тост «Нет миксов под эти настроения».
- Часть `getPlaylistTracks` упала (`allSettled`) → собираем из успешных; если пусто
  всё → тост-ошибка (переиспользуем существующий `setError`/тост-паттерн `startStation`).
- Дедуп по `track.id`; ограничения: 1–2 микса на настроение, `cap=60`.
- Во время сборки — `curateBuilding` блокирует повторный клик.

## 7. Тестирование

- **Unit (Vitest), `src/utils/curatedMix.test.ts`:**
  - `blendTracks`: round-robin порядок, дедуп по id, соблюдение `cap`, пустые/одиночные
    входы, устойчивость к спискам разной длины.
  - `pickMixesForMoods`: корректная группировка станций по настроениям, игнор
    не-`yt` станций, пустой результат для настроения без миксов.
- **Ручная проверка UI:** собрать микс из 2–3 настроений → станция появляется,
  играет, переживает перезаход в раздел; тосты на ошибках; чип/поповер работают
  на фоне уже починенной ленты фильтров.
